How it works

WordPress gives a clean technical foundation, but it does not manage the things search engines read first: meta titles, meta descriptions, schema markup and canonical URLs. Without a plugin, these are either missing or left to the theme.

The plugin adds them in one place. After installation a short setup asks what kind of site you run — a blog, a shop, a local business, a portfolio — and fills in sensible defaults for each type of content.

Meta titles and descriptions come from templates: the post title, the site name, the category, the product price. Any page can override the template with its own text, and a preview shows how the result will look in search results.

Structured data is added automatically for articles, products, organizations, local businesses and FAQ sections. It is generated from the content you already have, so you do not need to write code or copy markup by hand.

Canonical URLs are set on every page, so that the same content reachable at several addresses — with parameters, in archives, on paginated lists — is counted once.

The XML sitemap is kept current as you publish, update or delete content. Pages you mark as not for search are left out of it, and so are attachment pages, empty tag archives and other technical pages that only dilute the index.

New and updated pages are submitted through IndexNow, a protocol supported by several search engines, as soon as you save them. You do not have to wait for the next crawl to have a new product or article noticed.

A redirect manager handles moved and deleted pages. When you change a URL, the plugin offers to create a redirect from the old address, and a log shows requests that end on missing pages, so you can send them to the right place.

A short checklist on every post points out what is missing: no description, a title that is too long, an image without alternative text, a page that is excluded from the index by mistake.

The plugin works with the block editor and the classic editor, with common page builders and with WooCommerce product pages. Settings can be exported and imported, so agencies can apply the same setup to many sites.

Everything runs inside your WordPress installation; your content and settings stay on your own server.

The plugin is built for WordPress site owners, freelancers and small agencies anywhere. It is in preparation: we are checking whether site owners need it before it is built.
